# Deeper, Not Bigger

A self-contained, earthy visual edition of the supplied AI Influencer Playbook, positioned as a $50 educational product.

## Download

- [Download the PDF](Deeper-Not-Bigger-Playbook.pdf)
- [Download the interactive HTML](index.html)
- [Download both in one ZIP](AI-Influencer-Playbook.zip)

On GitHub, open a file and choose **Download raw file** if clicking the link opens a preview. If the repository is private, sign in to GitHub first.

- `index.html`: interactive playbook with embedded editorial image; no dependencies or build step.
- `Playbook.md`: concise editable text edition.
- `Deeper-Not-Bigger-Playbook.pdf`: printable edition generated from the HTML.
- `preview-desktop.png` and `preview-mobile.png`: visual previews.
- `cover-preview.png`: cover preview.
- `assets/hero.png`: generated editorial artwork, also embedded in the HTML.
- `originals/`: the two documents supplied by the user for reference.

Open `index.html` in a browser. For local development, run `python3 -m http.server 8080 --bind 127.0.0.1` from this directory. No API keys or account connections are needed. No purchase processing or publishing is configured.

The page includes saved checklists, a promise worksheet, hook builder, revenue scenario calculator, troubleshooting selector, copy buttons, CSV downloads, print support and progress reset. Local storage keeps data on the reader’s device; no form content is sent to a server. Clipboard fallback selects text if direct copying is unavailable.

The photo is an AI-generated editorial illustration. Olive branch decoration is inline SVG. All assets are embedded for offline use; official source links require internet access. The source document’s unverified dated policy claims and earnings anecdotes are not presented as facts in this revision.
