Good questions

A few things
worth knowing.

Do I need a website already?

No. You can start from scratch or improve an existing site. Leave the website field blank if you don’t have one.

What does a 72-hour launch mean?

It is a delivery target for a focused project after the scope, content, assets and start date are agreed. Your actual schedule will be confirmed before you commit.

Does submitting the form book an appointment?

No. A suitable project receives a scheduling link. Your appointment is booked only when the calendar confirms it.

What if I’m not ready to invest?

You’ll get a visibility checklist and a simple content planner you can download immediately. Start at your own pace.

Will I get automated calls or texts?

Only if you choose that optional contact preference and the follow-up service is active. You can still submit a request and use the scheduling link without opting in.
